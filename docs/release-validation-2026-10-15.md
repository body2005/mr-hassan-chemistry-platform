في التجهيز النهائي أُبقي العرض الميكانيكي لصيغ LaTeX والمؤشرات العلمية ومعالجة ترتيب رموز PDF، مع منع تحويل كلمات النثر parallel/quad/mid أو تغيير PH تخمينيًا. أزيل اختراع علامة موجب في إصلاح المساواة. هذا يحدّث وصف فصل التنسيق العلمي في تقرير المصدر السابق؛ لا توجد دعوى بأن حفظ Unicode وحده كافٍ للتمثيل الصحيح.

فحص تاريخ Git أعاد خمس مطابقات generic-api-key: بصمتا Docker موثقتان، ونص تعليمات اختبار، وقيمة توقيع خاطئة في اختبار401، ومفتاح idempotency اصطناعي. مراجعة السياق لم تثبت credential حقيقية في هذه المطابقات. نتيجة scanner التاريخية بقيت nonzero؛ لا suppression أو تغيير تاريخ لإخفائها. فحص التعديلات المجهزة للرفع يُعاد بعد staging النهائي، ولا تُضم ملفات البيئة أو الأدلة الخام.

النشر المطلوب يضم API على خدمة Render الحالية بنوع Python، والواجهة في مشروع Vercel mr-hassan-chemistry-platform، والعامل المحلي المنفصل. بناء Docker محلي لا يعني أن حماية native في الصورة أصبحت مثبتة في خدمة Render ذات runtime مختلف. لا خدمات مدفوعة أو اشتراكات DRM جديدة. حدود Extract/proxy/الاستعادة الكاملة المذكورة في تقرير المصدر تبقى قائمة حتى تحققها المستقل.

خطة التوافق: schema الإضافية ثم API المتوافق والعامل ثم الواجهة؛ عند التراجع يُعاد إصدار الكود السابق وتبقى الأعمدة والجداول الإضافية، دون إسقاط بيانات أو إزالة مؤشرات حماية. لا يساوي pg_dump وحده نسخة متسقة من قاعدة البيانات والملفات معًا، ولا يعني التحقق من archive نجاح restore.

نتائج النشر الفعلية وSHA والروابط تُتحقق بعد التنفيذ، ولا تُستنتج من نجاح البناء المحلي.
