## التراجع والحدود

صورة المعالج السابقة محفوظة باسم `chemistry-video-worker-pc:rollback-ecc1015`،
وإعداد الاتصال السابق محفوظ محليًا بصورة خاصة. التراجع إلى اتصال القاعدة
المنتهية لن يعيد الخدمة؛ احتفظ بالاتصال الجديد عند التراجع عن كود المعالج.
الرجوع عن كود API يحتفظ بالـschema الإضافية وبيانات المتابعة؛ لا downgrade
مدمر ولا استعادة قاعدة قديمة تلقائيًا.

Render ما زال خدمة Python المدارة، وليس صورة Docker التي اختُبرت محليًا؛
نجاح native gates للصورة والمعالج لا يثبت نفس مكتبات نظام مضيف Render.
لم يُعد فحص صور OS/native خارجيًا في هذه الجولة. لم تُنشأ دروس أو حسابات
طلاب إنتاجية لاختبار المشاهدة؛ لا تجربة جديدة لمشاهدة طالب مشتري أو IDM.

`VIDEO_DRM_REQUIRED=false` و`VIDEO_DRM_PACKAGING_ENABLED=false`؛ لم تُفعّل
حماية تتطلب مزود تراخيص غير مجهز. لا ادعاء بمنع تنزيل الفيديو للمشاهد
المصرح له أو تسجيل الشاشة. الأدلة الخام والصورة داخل `.qa/ecc-deploy-20261015/`
المستبعد من Git، مع إبقاء بيانات الاتصال خارج التقارير.
